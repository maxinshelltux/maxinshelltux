# Решение сценария 01: процесс перезапускает systemd

Инцидент: `broken/scenario-01/`. Процесс, занимающий память, принадлежит службе
`lab-memhog.service` с `Restart=always`, поэтому после `kill` появляется снова.

`fix.sh` находит процесс с наибольшим RSS, определяет его службу и останавливает
именно её:

```bash
ps -o unit= -p <PID>
systemctl stop lab-memhog.service
```

Если самый прожорливый процесс принадлежит другой службе, скрипт ничего не
останавливает и сообщает об этом.
