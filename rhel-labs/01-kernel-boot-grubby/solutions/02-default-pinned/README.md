# Решение сценария 02: ядром по умолчанию выбрано старое

Инцидент: `broken/scenario-02/`. Ядро по умолчанию задано индексом, который указывал
на старое ядро.

`fix.sh` находит самое новое ядро в `/boot` и задаёт его путём:

```bash
grubby --set-default /boot/vmlinuz-<самая новая версия>
```

После него нужна перезагрузка, затем проверка `uname -r`.
